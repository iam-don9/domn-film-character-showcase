# domn-film-character-showcase

> 独立技能仓库 · 来自 domn skills 集合（视频制作 域）

人物展示动画导演。为 AI 视频（可灵 Kling / 即梦 Seedance / Vidu / Runway / Pika / Luma / Veo / 海螺）生成「角色展示 / 角色亮相 / 英雄展示 / 角色 PV / 人物立绘动起来」的提示词与分镜时使用；也用于把一段人物设定文字转成分镜，或诊断已有展示片"看完记不住脸 / 不知道他会什么 / 感受不到性格"。 覆盖：角色档案八项提取（外貌锚点 / 能力体系 / 性格内核 / 故事钩子 / 台词 / 主场场景 / 声音质感 / 色彩光）、展示原型判定（王者荣耀型 / 鬼泣型 / 守望先锋型 / 只狼一击型 / 二次元大招型 / 格斗挑衅型 / 压迫登场型 / 反差日常型）、四拍结构（S0悬念 → S1登场 → S2展示 → S3签名定格）、时长分镜矩阵（5s / 10s / 15s / 30s）、性格→动作质感转译、展示镜头语法库与 ASCII 机位摆位、台词落位与**全程无字幕**规则、**画风随用户提供的角色而定（不自选）**与 Key Art 生图、多 clip 拆分与模型适配、一致性三锚点与负面词、7 类变体（双人/非人/Q版/只有立绘/≤3s 等）、25 条诊断。 只管「展示」：不写与敌人的完整对打（交给 domn-film-action-director），不写变身形态转换（交给 domn-film-henshin-director）。 触发词：人物展示、角色展示、角色亮相、英雄展示、人物介绍视频、角色 PV、角色预告、人设动画、角色登场、展示动画、character showcase、hero intro、character reveal、人物分镜、角色提示词。

# 11 变体与边缘场景

主干规则覆盖"单个原创/二次元角色的展示片"。下面是不适用主干的边缘情形及其改写规则。

## 1. 变体总表

| 变体 | 触发 | 主干规则的哪条要让步 | 改写要点 |
|---|---|---|---|
| **V1 双人 / 群像** | 用户要展示 2 人以上 | H1 单人主体 | 见 §2 |
| **V2 无超能力的写实角色** | 历史人物、职业角色、真人 | S2 的"能力展示"无处安放 | 见 §3 |
| **V3 非人角色** | 动物、机甲、怪物、吉祥物 | 外貌锚与"脸"的定义 | 见 §4 |
| **V4 Q 版 / 吉祥物** | 二头身、卡通 | 帅气 Pose 不适用 | 见 §5 |
| **V5 只有一张立绘** | 输入仅一张图 | 参考图只有 1 张 | 见 §6 |
| **V6 极短（≤3s）** | 竖屏短视频、循环动图 | 四拍放不下 | 见 §7 |
| **V7 已有配音/台词音频** | 先有声音再有画面 | 台词时间码被锁死 | 见 §8 |

## 2. V1 双人 / 群像

- **总时长 +50%**：每人至少分到 S1 一次。
- **S1 改为接力式**：A 先亮相 → A 的 S2 末尾引出 B → B 的 S1 → 共同的 S3。
- **锚点加倍**：每人一组外貌锚 + 色彩锚，两人主色必须能区分。
- **S3 必须同框**：群像的签名帧是"合影 Pose"，不许各定各的。
- **台词**：只允许一句，由其中一人说（或两人各半句，总长仍 ≤ 15 字）。
- **人数上限 3**：超过 3 人不是展示片，是群像预告，改用其他模板。

## 3. V2 无超能力的写实角色

"能力展示"换成**专业动作展示**：

| 角色 | 换成什么 |
|---|---|
| 医者 | 一次精准的操作、缝合、握刀的手稳 |
| 武将 | 一记干脆的拔刀 / 上马 / 号令 |
| 工匠 | 一锤定音、一件成品成形 |
| 学者 | 提笔、推演、抬头 |

- 用**职业道具**当能力锚（听诊器 / 刀 / 锤 / 笔）。
- S2 的"慢动作高光"改为**手的特写 + 一次决定性动作**。
- 不追加不存在的超能力——这是"展示"，不是"魔改设定"（`01 §2` A 类同理）。

## 4. V3 非人角色

- **外貌锚**：换成剪影特征（轮廓、颜色分区、标志部件）。
- **"脸"**：动物给眼睛，机甲给光学镜头 / 面甲发光，怪物给最像脸的部位。
- **能力锚**：与生物/机械特性绑定（飞行、变形、吐息）。
- **性格转译仍然适用**（`01 §4`），尤其"机械/非人"那一栏。
- **S3**：给一个能被截图的形态 Pose，不要让它在运动中被定格。

## 5. V4 Q 版 / 吉祥物

- 原型默认 **P8 反差日常** 或 **P6 挑衅爆发**，帅气型（P4/P7）不适用。
- S2 的动作改为**弹性动作**（弹跳、摇摆、夸张变形）。
- 签名 Pose 要**简单可辨**（张开双臂 / 比心 / 叉腰），复杂 Pose 在 Q 版下会糊。
- 慢动作改为**弹性停顿**（squash & stretch 的顶点停 0.2s）。

## 6. V5 只有一张立绘

- 这张图当**图 1 角色图**，场景图由提示词生成（不强制要图 2）。
- **画风以立绘为准**：锁定块按立绘画风写，不许另起一套。
- 立绘是正面站姿时，**S1 的 Pose 与立绘对齐**，避免模型"纠正"姿态。
- 若立绘带背景，提示词里写"背景另设"并写明目标主场，防止模型沿用原背景。

## 7. V6 极短（≤3s）

- 只保留 **S1 登场（1s）+ S3 定格（1s）+ 余韵（0.5s）**。
- S2 压缩为一个**起手动作**（不完成），留给观众脑补。
- **不说台词**（3 秒内开口说台词必然局促），走 C 式纯画面表达。
- 优先做成**可循环**：尾帧姿态 ≈ 首帧姿态。

## 8. V7 已有配音 / 台词音频

- 台词时间码**以音频为准**，四拍时长反过来适配音频（先定 S3 的起止，再倒推 S1/S2）。
- 口型必须对齐：提示词写明"口型与提供的音频同步"。
- 若音频长于画面：加长 S3 的余韵，不加速动作。
- 仍然**不许出现字幕**（H10）——有配音不等于要字幕。

## 9. 边缘情形的通则

> **主干规则是默认值，不是教条。**
> 让步时必须：① 说明让的是哪条 ② 说明为什么 ③ 交付时注明"本片为 Vx 变体，让步 H#"。
> **永远不让步的三条**：H2（能力可见发生）、H7（锚点贯穿）、H10（无字幕）。

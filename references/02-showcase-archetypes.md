# 02 展示原型 P1–P8

先判原型，再排分镜。**原型决定节奏、机位、能量曲线。**

## 判定决策树

```
Q1 他有没有强烈背景故事 / 原作台词？
   ├ 有，且要观众"懂他这个人" → P3 角色独白型
   └ 主要看技能与帅 → 下问
Q2 他的魅力核心是什么？
   ├ 技能的识别度（观众要记住"这招是他的"） → P1 王者归来型
   ├ 手感与态度（连段、耍帅、挑衅）      → P2 华丽炫技型
   ├ 压迫感与一击必杀（极静→极动）       → P4 一击定生死型
   ├ 华丽大招与元素演出                  → P5 元素爆发型
   ├ 戏谑与幽默感                        → P6 挑衅爆发型
   ├ 体量与恐惧（Boss / 君王 / 反派）    → P7 压迫登场型
   └ 日常与战斗的反差                    → P8 反差日常型
Q3 是否混搭？
   └ 允许，但必须以一种为主（例：P2 骨架 + P3 的独白尾）
```

## 原型详表

### P1 王者归来型（王者荣耀英雄展示）
- **看点**：登场定格 + 招牌技能循环 + 台词，强调**技能识别度**
- **能量曲线**：中起 → 阶梯上升 → 定格平台（可循环回起点）
- **节拍**：S0 武器/局部 → S1 转身亮相（明确 Pose）→ S2 招牌技 1–2 次（每次收在一个可辨识姿态）→ S3 大字 Pose + 台词
- **机位**：正面低角度仰拍为主，S1 与 S3 机位几乎相同（形成"回环"）
- **适配**：MOBA / 二次元 / 需要技能辨识度的角色
- **禁忌**：S1 与 S3 姿势差异过大，导致"可循环感"丢失

### P2 华丽炫技型（鬼泣 DMC）
- **看点**：连段、挑衅、耍帅收刀，**态度 > 战力**
- **能量曲线**：快起 → 高密度 → 突然停顿 → 收
- **节拍**：S0 一个慵懒小动作 → S1 一次高速位移入场 → S2 连段（3–5 个动作不落地）→ 中途一次 0.3s 停顿耍帅 → S3 收武器 + 不看镜头
- **机位**：贴身跟拍 + 侧位横移，允许镜头被主体遮挡
- **适配**：刺客、剑客、双枪、高机动
- **禁忌**：动作之间"落地喘息"，会掉手感

### P3 角色独白型（守望先锋 Hero Intro）
- **看点**：一边演一边说，**人格与故事外露**
- **能量曲线**：平缓 → 情绪爬升 → 尾句落下
- **节拍**：S0 环境空镜 + 角色声音先入 → S1 半身入画（常是侧脸）→ S2 边说边做一件日常却有分量的事 → S3 直视镜头说完最后一句
- **机位**：中近景为主，浅景深，偶尔过肩
- **适配**：有强烈背景故事 / 有台词 IP
- **禁忌**：台词与画面各说各的；**不许出字幕**（H10）

### P4 一击定生死型（只狼 / 仁王）
- **看点**：长久静止 → 一闪 → 收刀
- **能量曲线**：平 → 尖峰（0.5s）→ 平
- **节拍**：S0 长时间静止（雨/雪/呼吸）→ S1 只给局部（手按刀柄、眼）→ S2 一次斩击（**全片唯一一次高速**）→ S3 收刀 + 环境恢复静止
- **机位**：固定机位为主，斩击瞬间允许一次推近
- **适配**：武士、忍者、狙击手、压迫感反派
- **禁忌**：斩击后再追加任何动作（追加即破功）

### P5 元素爆发型（原神 / 星穹铁道）
- **看点**：蓄力 → 元素爆发全屏 → 眼神特写
- **能量曲线**：缓升 → 全屏爆 → 静
- **节拍**：S0 元素粒子在环境中聚集 → S1 角色睁眼 / 抬头 → S2 蓄力（慢）→ 爆发（快，全屏变色）→ S3 爆发余韵中给眼部特写
- **机位**：S2 环绕 + S3 极近特写（眼）
- **适配**：法师、元素系、少女系
- **禁忌**：爆发后不收，画面一直亮到最后

### P6 挑衅爆发型（街霸 / 拳皇）
- **看点**：嘲讽 → 爆发 → 定格
- **能量曲线**：低（戏谑）→ 骤升 → 硬定格
- **节拍**：S0 一个轻佻小动作 → S1 勾手 / 挑眉 → S2 一套爆发连击 → S3 定格 + 笑
- **机位**：略仰拍，允许广角畸变
- **适配**：格斗家、痞气角色
- **禁忌**：把挑衅演成恶意（会变反派）

### P7 压迫登场型（魂系 / FF 反派）
- **看点**：不炫技，靠**体量与气氛**
- **能量曲线**：全程缓升，无尖峰
- **节拍**：S0 环境被影响（火灭、鸟飞、水倒流）→ S1 从暗处走出（**先看影子后看人**）→ S2 一步一震，不出招 → S3 站定，抬眼
- **机位**：低机位仰拍 + 大远景，慢推
- **适配**：Boss、君王、反派
- **禁忌**：让角色做灵活动作（会掉体量）

### P8 反差日常型（蜘蛛侠 / 日常系）
- **看点**：先示弱 / 日常 → 一秒切战斗态
- **能量曲线**：松 → 骤紧 → 松（带笑）
- **节拍**：S0 完全日常（吃东西、发呆、淋雨）→ S1 察觉异样（只给反应）→ S2 一秒切战斗态（**切换点必须有明确触发**）→ S3 回到松弛 + 台词
- **机位**：S0 手持感，S2 后转稳定
- **适配**：双面身份、少年热血
- **禁忌**：切换无触发（观众跟不上）

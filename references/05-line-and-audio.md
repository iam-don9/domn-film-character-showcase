# 05 台词与声音（全程无字幕）

> **H10：画面内禁止出现任何字幕、标题、花字、台词条、UI 文字。**
> 台词只能靠**角色发声**或**声音层**传达。本文件所有规则都建立在这条之上。

## 1. 台词的三种合法呈现

| 式 | 名称 | 画面里有什么 | 提示词怎么写 | 何时用 |
|---|---|---|---|---|
| **A** | **角色发声**（推荐） | 角色开口说话，**口型与台词同步**，配音出人声；**无字幕** | `opens his mouth and speaks the line, lips moving in sync, no subtitle, no text on screen` | 模型支持口型 / 后期配音对轨 |
| **B** | **声音层** | 画面只有表情、气息、动作；台词由配音 / 旁白承担；**无字幕无口型** | `the character turns and looks at camera, breathing steady, no mouth movement, no text` | 模型做不了口型时**自动降级**为此式 |
| **C** | **纯画面表达** | 完全不出现这句台词，用眼神、收势、环境变化传达同一含义 | 不写说话，只写动作与情绪 | 台词难落地 / 追求极简 |

**降级规则**：模型不支持口型 → A 自动降 B，并在交付中注明"本镜台词走配音，画面无字幕无口型"。**绝不因为不好做就退回加字幕。**

## 2. 台词内容规则

1. **性质**：表达**价值观**，不做自我介绍、不报技能名。
   - ❌ "我是暗影刺客，擅长暗杀。"
   - ✅ "黑暗，也不收留说谎的人。"
2. **位置**：只在 S3（或 S2→S3 转折点），**不早于总时长 60%**（H4）。
3. **长度**：中文 8–15 字；超过拆两行，断点落在语义处。
4. **数量**：**全片一句**。第二句只在 30s 档允许（S0 一句 + S3 一句，形成首尾呼应）。

### 生成三式（原作无台词时按性格选）

| 式 | 适配性格 | 结构 | 示例 |
|---|---|---|---|
| **宣言式** | 傲慢 / 热血 / 坚定 | 一句不可置疑的判断句 | "这天下，我替他守着。" |
| **留白式** | 阴郁 / 冷静 / 神秘 | 半句话，剩下一半交给画面 | "如果那天下的是雨……" |
| **反差式** | 温柔 / 悲壮 / 幽默 | 温柔语气说残酷的事（或反之） | "别怕，很快就结束了。" |

> **反例清单**：自我介绍、技能名播报、世界观解说、"我是为了……而战"——全是解说，不是台词。

## 3. 声音层设计（无字幕后，声音承担一半信息）

| 层 | 内容 | 写法 |
|---|---|---|
| **人声** | 台词配音 / 气息 / 笑 / 呼吸 | 音色（沙哑 / 清亮 / 少年）、语速、尾音处理 |
| **动作音** | 脚步、拔刀、收刀、衣摆、金属 | 必须**逐拍点名**，这是"质感"的主要来源 |
| **能力音** | 元素发动、能量充能、召唤 | 与能力锚的**颜色与形状绑定**（听觉识别子） |
| **环境底噪** | 风、雨、雪、火、虫鸣、城嚣 | 全片统一，作为时间连续性的听觉锚 |
| **静音** | S3 定格前后的 0.3–0.5s | **刻意留白**，比加音效更有力 |

**三条硬规矩**
1. S3 说台词时，**动作音必须让位**：不能有盖过人声的爆炸或金属撞击。
2. 能力音在全片**保持同一音色**，换 clip 不能换声。
3. 结尾余韵（H9）配"声音收住"——最后一个音衰减完，不留残响。

## 4. 语言默认

- 已有 IP：与原作语言一致。
- 原创角色：默认**中文**；用户指定则随用户。
- 交付时给**台词原文 + 罗马音/外文版本（如需）**，供配音使用。

## 5. 输出卡片模板（**无字幕字段**）

```
台词：「……」
时间码：X.Xs – X.Xs
呈现方式：A 角色发声（口型同步）/ B 声音层（配音，无口型）/ C 纯画面表达
画面要求：中近景，嘴部无遮挡，直视镜头（A/B 式必写）
配音：音色 / 语速 / 情绪 / 语言
声音让位：S3 期间动作音压低
字幕：**无（H10）**
```

## 6. 逐镜提示词里的固定写法

- 中文：`角色开口说出台词，口型与台词同步；画面内不出现任何字幕与文字。`
- EN：`the character speaks the line with visible lip movement; no subtitle, no caption, no text, no typography, no title card on screen.`

## 7. 配乐（可选层）

| 拍 | 配乐处理 |
|---|---|
| S0 | 单乐器进入（或一个持续音），建立气质 |
| S1 | 主旋律起，或一记明确的重音点题 |
| S2 | 节奏层加入，与动作同频 |
| S3 | **音乐收住或只留一个持续音**，给人声与余韵让位 |

- 配乐**不许盖过人声**：S3 若走 A 式，音乐必须降下来。
- 主题性：角色片建议有一个**可重复的音乐动机**（2–4 音），对应能力锚。
- 若不做配乐，用**环境底噪 + 动作音**足够，不必强加。

## 8. 自检

- [ ] 全片任何一镜的提示词里都没有 subtitle / caption / 字幕 / 花字 / 标题
- [ ] 台词出现时间不早于 60%
- [ ] 若用 A 式，画面给了嘴部可见的中近景
- [ ] 负面词逐镜带上了无字幕条目（见 `06 §3`）
- [ ] 环境里没有招牌、横幅、屏幕 UI 等易生乱码的文字元素

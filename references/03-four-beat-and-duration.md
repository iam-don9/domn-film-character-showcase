# 03 四拍结构与时长矩阵

## 1. 四拍（S0–S3）：所有展示动画的共同骨架

| 拍 | 名称 | 默认占比 | 任务 | 常见手法 | 失败症状 |
|---|---|---|---|---|---|
| **S0** | 悬念 / 缺席 | 0–15% | 建立气氛，让人"还没出现就感到存在" | 空镜、局部特写（脚/手/武器/影子）、环境异动 | 一上来就是脸，没有期待 |
| **S1** | 登场 Reveal | 15–40% | 人物**第一次完整可见** | 剪影入场 → 光打到脸；局部上摇到脸；环绕半圈 | 观众没看清是谁 |
| **S2** | 展示 Showcase | 40–75% | 能力具象化 + 性格外露（能量最高点） | 招牌技 + 慢动作高光 + 环境压制 | 能力只靠旁白或文字 |
| **S3** | 签名定格 Signature | 75–100% | 留一帧可截图的 Pose + **台词** | 收势（归鞘/披风落/光点散）+ 看向镜头 | 没有余韵、硬切黑 |

**秩序不许改**（不许先展示后登场）；比例按原型调（见 `02` 末尾表）。

## 2. 时长矩阵（clamp 规则）

> 总时长 = 各镜之和，误差 ≤ 0.5s（H6）。单 clip 上限按模型取 5s / 10s（见 `07`）。

### 5s（1–2 clip）
| 拍 | 时长 | 内容 |
|---|---|---|
| S1 登场 | 1.5s | 直接给脸，剪影入场或局部上摇 |
| S2 展示 | 2.0s | **只演一个能力动作**，一次完成 |
| S3 定格 | 1.5s | 收势 + 台词（发声） |

- S0 省略，但要用**一个环境元素**替代（开场即风/雪/光尘）
- 允许 1 clip 完成（10s 上限模型）

### 10s（2–3 clip）
| 拍 | 时长 | 内容 |
|---|---|---|
| S0 局部 | 1.5s | 脚/手/武器/影子 |
| S1 登场 | 2.5s | 完整亮相 |
| S2 能力展示 | 3.5s | 招牌技 + 一次慢动作高光 |
| S3 定格 | 2.5s | 收势 + 台词 |

### 15s（3–4 clip）
| 拍 | 时长 | 内容 |
|---|---|---|
| S0 氛围 | 2.0s | 主场环境 + 角色缺席的存在感 |
| S1 登场 | 3.5s | 完整亮相 + 一次环绕 |
| S2a 招牌技 | 4.0s | 能力具象化 |
| S2b 性格高光 | 3.0s | 一个只属于他的小动作 / 表情 |
| S3 定格 | 2.5s | 收势 + 台词 |

### 30s（5–7 clip）
| 拍 | 时长 | 内容 |
|---|---|---|
| S0 氛围 + 故事钩子 | 4.0s | 环境 + 一个象征细节 |
| S1 登场 | 5.0s | 完整亮相 + 环绕 |
| S2a 招牌技 | 5.0s | 能力具象化 |
| **闪回 / 执念物** | **4.0s** | **唯一的故事窗口**（怀表、断刀、旧照片、伤疤） |
| S2b 大招全开 | 7.0s | 能量最高点 |
| S3 定格 | 5.0s | 收势 + 台词 + 余韵 |

**30s 专属**：中段必须插一次闪回或执念物特写——这是"告诉观众他有怎样的故事"的唯一窗口（H2 的正向用法）。5–15s 用**象征细节**代替闪回。

## 3. 闪回插入的三条规矩

1. **时长 ≤ 总时长 15%**（30s 片 ≤ 4.5s），长了变回忆录。
2. **只闪一个画面**，不闪一段过程（AI 视频做不好连续闪回）。
3. **冷暖反差**：闪回段的色温必须与战斗段明确不同（暖黄 / 冷蓝二选一），否则观众分不清时间层。
4. **回到现实必须有触发**：一声、一道光、一次眨眼，不许硬切回来。

## 4. clip 拆分速查

| 目标 | 5s 上限模型 | 10s 上限模型 |
|---|---|---|
| 5s | 1 | 1 |
| 10s | 2（5+5） | 1–2 |
| 15s | 3（5+5+5） | 2（10+5） |
| 30s | 6 | 3–4 |

拆分与衔接细则见 `07`。

## 5. 余韵（H9）

- S3 之后固定保留 **0.3–0.5s 静止**：角色不动、镜头不推、特效只剩消散。
- 这 0.3–0.5s 是"观众截图"的窗口，**不许填满**。
- 不硬切黑，优先自然衰减（光点散尽 / 尘土落下 / 声音收住）。

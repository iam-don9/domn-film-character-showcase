## 2. 最短交付（M4 定位 / 快速问询时）

只出：③ 时长预算表 + ④ 分镜表 + ⑦ 一致性清单。其余省略。

## 3. 质检清单（交付前逐条自查）

- [ ] 三锚点在每一镜都能找到，措辞一致
- [ ] 全片只有一个主体，没有形成对打（H1）
- [ ] 能力至少在画面里完整发生一次（H2）
- [ ] 每镜只讲一件事（H3）
- [ ] 台词不早于 60% 时长，且全片只有一句（H4）
- [ ] S3 的 pose / 构图 / 机位写到了可执行粒度（H5）
- [ ] 各镜时长之和 = 目标时长，误差 ≤ 0.5s（H6）
- [ ] 每镜至少一个锚点可见（H7）
- [ ] 没有完整战斗流程（H8）
- [ ] S3 后留了 0.3–0.5s 余韵（H9）
- [ ] **画风来自用户提供的角色图 / 明写的词 / IP 原作，不是我替他选的（H11）**
- [ ] 锁定块逐镜一字不改，闪回也没换画风
- [ ] **全片无任何字幕 / 标题 / 花字 / 屏幕文字，负面词逐镜带上（H10）**
- [ ] 相邻 clip 尾帧 = 下一 clip 首帧（`07 §4`）
- [ ] 参考图每 clip 都带（`07 §5`）
- [ ] 30s 档中段有闪回或执念物（`03 §2`）

## 4. 范例：10s · P2 华丽炫技型（无字幕版）

**输入**：白鸦，原创角色。白衣黑发的年轻剑客，纸鹤术士，表面漫不经心实则极度记仇，失去过整个师门。台词："我记得每一只没能飞回来的鹤。"
**用户提供**：一张角色设定图（厚涂插画风，可见笔触，柔光，哑光布料）。

### ⓪ 画风锁定块

```
画风来源：用户提供的角色设定图（最高优先级）
锁定块：painterly 2D animation, soft visible brushwork, rich gradient shading,
        single soft cinematic key light, matte fabric texture, subtle grain, shallow DoF, 50mm
必禁词：flat cel-shading, clean line art, photorealistic, 3D render, glossy plastic
全片共用：是
```
> 注意：这里没有"挑一档"，是**从图上读出来的**。若用户没给图也没说，就问，不代填。

### ① 档案卡（摘要）

| 项 | 内容 |
|---|---|
| 外貌锚点 | 白衣 + 墨黑长发 + 细长直刀 |
| 能力体系 | 纸鹤术（折纸化鹤 / 群鹤爆发）→ 一刀断念；移动：踏雪疾走 |
| 性格内核 | 漫不经心 + 记仇 → 动作质感：慵懒起手、收势极干净 |
| 故事钩子 | 失去整个师门（守护失败）→ 象征细节：始终随身的一只旧纸鹤 |
| 台词 | "我记得每一只没能飞回来的鹤。" |
| 主场 | 雪原 |
| 声音 | 雪落、纸张摩擦、刀鸣 |
| 色彩光 | 雪白 / 墨黑 / 冷白光，主光始终来自画面左侧 |

**一句话人物真相**：他是一个把所有痛苦都折成了纸，慢慢还回去的人。

### ③ 时长预算

| 拍 | 时长 | clip | 信息 | 语法 |
|---|---|---|---|---|
| S0 局部 | 1.5s | C1 | 雪地上落着一只纸鹤 | G2 局部先行 |
| S1 登场 | 2.5s | C1 | 白衣剑客背对镜头立于风雪 | G1 剪影入场 |
| S2 展示 | 3.5s | C2 | 拔刀一闪，纸鹤炸成数百只绕身疾飞 | G5 轨迹留光 + G4 慢动作 |
| S3 定格 | 2.5s | C2 | 收刀入鞘，抬头看镜头，开口说台词 | G9 打破第四面墙 + G10 收势 |

### ⑤ 逐镜提示词

> 以下每条模型提示词**均以 ⓪ 的锁定块开头**，此处为免重复略去，实际输出时逐镜原样带上。

**C1（0–4s）**
- 中文：雪原空镜，一只白色纸鹤落在雪面并振翅起飞；镜头缓慢上摇，白衣黑发年轻剑客背对镜头立于风雪中，纸鹤自他右肩飞离，风雪横向掠过。
- 模型提示词（中）：雪原空镜，浅景深，一只白纸鹤落在雪面上并振翅起飞；镜头缓慢上摇，白衣黑发的年轻剑客背对镜头站立，纸鹤从他右肩飞离，风雪横向掠过，单侧冷白主光自画面左侧打入，电影感，85mm，慢速上摇。**画面内不出现任何文字与字幕。**
- EN：Wide snowfield, shallow depth of field, a single white paper crane lands on the snow then takes off; camera tilts up slowly revealing a young swordsman in a white robe with long black hair, standing with his back to camera, the crane lifting off his right shoulder, snow drifting laterally, single cold key light from camera left, cinematic, 85mm, slow tilt up. No text, no subtitle, no caption anywhere on screen.
- 首帧：雪面特写，一只白纸鹤静止，背景虚化雪原。
- 尾帧：剑客背面中景，纸鹤位于画面右上，白衣下摆向右飘。
- 负面词：通用 + 无字幕 + `多人主体、武器消失、光源方向突变`。

**C2（4–10s）**
- 中文：他侧身拔刀，一道白光横扫，肩头纸鹤瞬间炸开成数百只绕身疾飞；慢动作中纸鹤化作流光轨迹；随即收刀入鞘，群鹤散尽，他微微抬头直视镜头，**开口说出台词，口型与台词同步**，雪停。
- 模型提示词（中）：白衣黑发的年轻剑客侧身拔刀，一道白色光弧横扫，纸鹤炸开成数百只绕着他高速盘旋并化为流光轨迹；动作在爆发瞬间放缓；随后他收刀入鞘，群鹤散尽，微微抬头直视镜头，**开口说台词，口型与台词同步**；雪停。冷白主光仍在画面左侧，中近景，浅景深。**画面内不出现任何文字与字幕。**
- EN：The young swordsman in a white robe with long black hair draws his slender blade in one clean arc; the paper crane bursts into hundreds of cranes swirling around him, dissolving into streaks of cold white light; the moment slows down; then he sheathes the blade in one motion, the cranes scatter, he looks up slightly and speaks the line directly to camera with visible lip movement synced to his voice; the snow stops. Cold key light still from camera left, medium close-up, shallow depth of field. No text, no subtitle, no caption, no title card on screen.
- 首帧：剑客背面中景，纸鹤位于画面右上，白衣下摆向右飘（= C1 尾帧）。
- 尾帧：剑客正面中近景，刀已归鞘，直视镜头，嘴微张正在说话，嘴角淡淡笑意。
- 负面词：通用 + 无字幕 + `口型不同步、动作断裂、爆发后不收、全屏过曝`。

### ⑥ 台词 / 声音卡

```
台词：「我记得每一只没能飞回来的鹤。」
时间码：8.0s – 9.8s
呈现方式：A 角色发声（口型同步 + 后期配音）
画面要求：中近景，嘴部无遮挡，直视镜头
配音：青年男声，音色清冷偏轻，语速慢，尾音下沉；中文
声音让位：说话期间刀鸣与振翅声压低，仅留雪落底噪
字幕：无（H10）
```

### ⑦ 一致性清单

- 外貌锚：白衣 + 墨黑长发 + 细长直刀（逐镜首句一字不改）
- 能力锚：白色纸鹤 + 冷白流光，运动方向恒为**绕身逆时针**
- 色彩锚：雪白 / 墨黑 / 冷白光，主光始终来自画面左侧

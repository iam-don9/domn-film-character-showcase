# 01 角色档案八项与信息提取

一切展示片的地基。**档案抽错，后面全错。**

## 1. 八项档案（Dossier）

| # | 项 | 抽什么 | 抽不到时的默认 |
|---|---|---|---|
| 1 | **外貌锚点** | 能被**剪影**认出的 2–3 个：发型/头饰、武器/道具、服装轮廓、伤疤/瞳色/义体 | 取「武器 + 一个头部特征」 |
| 2 | **能力体系** | 属性、招牌技（小）、大招（大）、移动方式（飞行/瞬移/疾走） | 取设定里最独特的那个动作 |
| 3 | **性格内核** | 3 个形容词 → **必须转译为动作质感**（见 §4） | 从台词与经历反推 |
| 4 | **故事钩子** | 失去过什么 / 守护什么 / 恨谁 / 背负什么 | 用"一个未完成的执念" |
| 5 | **台词** | 原作台词优先；没有则生成一句 8–15 字宣言（见 `05`） | 见 `05 §2` 三式 |
| 6 | **主场场景** | 他最有归属感的地方 | 取与其能力强相关的环境 |
| 7 | **声音质感** | 脚步、武器、元素、环境底噪 | 取"一种金属声 + 一种自然声" |
| 8 | **色彩与光** | 主色、辅色、光源方向、空气感（尘埃/雨/雪/烟） | 主色取设定色，统一单侧主光 |

> **画风不在八项里。** 画风不是"抽"出来的，是**读**出来的——它属于用户的物料，不属于你的判断（`10`、H11）。开工第一步（⓪）先读画风，再抽这八项。

## 2. 输入分三种，处理不同

| 输入 | 判定 | 处理 |
|---|---|---|
| **A 已有 IP** | 王者英雄 / 动漫 / 游戏 / 影视角色 | **先检索**真实技能、台词、配色、主场。**不许改设定**，只做视听转译。原作有展示动画的（王者英雄展示、OW Hero Intro、鬼泣角色演示）优先对齐其招牌动作 |
| **B 原创人设** | 一段文字描述 | 按八项抽取；**信息与八项冲突时以用户文字为准**。允许询问 1 次补关键缺项 |
| **C 只有名字或一句话** | 信息量极低 | **最多反问 3 个问题，画风排第一**：① 他是什么画风（或有参考图吗）② 他最强的一个能力是什么 ③ 他是什么性格、最想守护或报复什么（②③可合并成一问）。其余按默认值补齐并**明确标注「推定」** |

> 反问原则：**不反问就能开拍的，就不要反问。** C 类只问这 3 个，且允许一次性合并成一问。

## 3. 提取优先级（信息矛盾时）

```
用户明说的设定  >  原作事实  >  从外貌/经历合理推定  >  类型默认值
```

## 4. 性格 → 动作质感转译表（核心）

性格是形容词，镜头读不懂。必须翻译成可执行的动作。

| 性格 | 动作质感 | 可直接写进提示词的动作 |
|---|---|---|
| 傲慢 / 自信 | 慢半拍、不设防、单手、回眸 | 背对假想敌抬手格挡、侧头回看镜头、单手持武器垂于身侧 |
| 冷静 / 精准 | 极简、无多余动作、一击 | 只拔一次刀、收刀、没有第二次挥 |
| 癫狂 / 失控 | 不规则节奏、突然贴脸 | 抖肩笑、猛地凑近镜头、动作中途卡顿 |
| 悲壮 / 沉重 | 重落地、抬眼、慢 | 单膝跪地撑刀、雨水顺刀锋滴落、抬眼看天 |
| 温柔 / 守护 | 收力、护住、指尖光 | 伸手挡在镜头前、指尖凝聚一点光、把人护在身后 |
| 少年 / 热血 | 冲、跳、喊、逆光 | 冲刺起跳、逆光张开手臂、落地扬起尘土 |
| 阴郁 / 神秘 | 半遮面、烟雾、只露局部 | 斗篷遮半脸、烟雾中只露眼、镜头被手挡住 |
| 疲惫 / 老练 | 慢、稳、带伤 | 擦刀、点燃一支烟、拍掉肩上的灰 |
| 优雅 / 贵族 | 对称、克制、旋转 | 转身甩披风、抬手示意、足尖点地回旋 |
| 机械 / 非人 | 无呼吸感、卡顿、精确 | 头部以固定角度转向、动作无预备、关节无缓冲 |

> 一条片子**只选一个主性格**驱动动作质感；第二个性格只用来做 S3 的反差（例：全程傲慢 → 最后一秒露出一瞬疲惫）。

## 5. 故事钩子的三种视觉落法

| 钩子类型 | 5–15s 的象征细节 | 30s 的闪回插入 |
|---|---|---|
| 失去过什么 | 随身旧物、空了的第二副手套、缺口的刀 | 闪回：手松开、火光、背影远去 |
| 守护什么 | 下意识护住的动作、始终不远离某个方位 | 闪回：一个被护住的人的背影 |
| 恨谁 / 复仇 | 特定的伤疤、只在这种时候变冷的眼神 | 闪回：仇人的剪影 + 角色瞳孔收缩 |

**反例**：把故事写成"旁白交代他曾经……"。**故事只能给画面，不给解说。**（H2）

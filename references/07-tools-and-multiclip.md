# 07 工具适配与多 clip 拼接

> 工具能力迭代很快。下表为**通用基线**，落笔前如有可能请核对官方文档；不确定的项一律按"最保守"处理。

## 1. 选型三问

1. 单 clip 能出几秒？（决定拆几段）
2. 支持几张参考图？（决定能不能锚住角色一致性）
3. 支持首帧 / 尾帧 / 首尾帧吗？（决定衔接方式）

## 2. 通用基线表

| 能力 | 说明 | 展示片的用法 |
|---|---|---|
| 单 clip 时长 | 主流 5s 或 10s 两档 | 按 `03 §4` 拆 |
| 参考图 | 角色展示片**强依赖**参考图 | 每 clip 都带，不只第一镜 |
| 首帧 / 尾帧 | 用尾帧 = 首帧做动作接续 | 见 §4 |
| 运镜控制 | 部分模型支持显式运镜参数 | 不支持时把运镜写进描述 |

## 3. 保守原则（不确定时）

- **按 5s 拆**，宁可多拆一段。
- **每张 clip 都挂角色参考图 + 场景参考图**。
- 不依赖尾帧锁死中间动作——**中间动作交给提示词**，帧控制只管首尾姿态（与 `domn-film-henshin-director` 同源经验：帧控制锁太死会让中间"卡住"）。

## 4. 衔接四规则

1. **尾帧 → 首帧同源**：上一镜的尾帧描述**原样复制**为下一镜的首帧描述。
2. **动作接续优先**：用挥砍的收尾 → 下一镜的起手，比硬切自然。
3. **遮挡转场**：披风 / 火光 / 烟 / 尘土扫过全屏时切，最不容易穿帮。
4. **运镜方向连续**：上一镜向左环绕，下一镜不从右侧反向起。

## 5. 参考图策略

| 图 | 内容 | 必要性 |
|---|---|---|
| **图 1 角色** | 正面全身或七分身，含外貌锚点全部可见 | **必需**，每 clip 都挂 |
| **图 2 场景** | 主场环境，含正确的光向与空气感 | **必需** |
| 图 3 特写（可选） | 面部 / 武器 / 执念物 | 30s 档或 S3 用 |

- 参考图描述中**不许出现文字**（招牌、UI），否则模型容易把字带进画面（H10）。
- 角色图的**光向必须与成片一致**，否则每 clip 的光都会漂。

## 6. 30s 档的拆法示例（5s 上限模型）

| clip | 对应拍 | 时长 | 首帧 | 尾帧 |
|---|---|---|---|---|
| C1 | S0 + S1a | 5s | 环境空镜 | 角色剪影立于光中 |
| C2 | S1b + S2a | 5s | 角色剪影立于光中 | 招牌技起手，能量在手中成形 |
| C3 | S2a 完成 | 5s | 招牌技起手 | 技法命中，冲击波扩散 |
| C4 | 闪回 / 执念物 | 4s | 冲击余韵 | 执念物特写（冷暖反差） |
| C5 | S2b 大招 | 7s→拆 2 clip | 抬眼回到现实 | 大招全开，全屏变色 |
| C6 | S3 定格 | 5s | 大招余韵 | 签名 Pose，直视镜头说台词 |

## 7. 交付时必给的工具字段

每镜输出中必须包含：
- 本镜时长
- 参考图编号（图 1 / 图 2 / 图 3）
- 首帧描述 / 尾帧描述（或注明"本镜不适用"）
- 与前后 clip 的衔接方式（动作接续 / 遮挡转场 / 同源帧）

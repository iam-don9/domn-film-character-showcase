# 04 镜头与运镜语法库

每拍取 **1–2 个**语法，全片总量控制在 **3–5 个**。堆满 = 没有重点。

## 1. 语法库

| # | 语法 | 适用拍 | 提示词要点 | 参数建议 |
|---|---|---|---|---|
| G1 | **剪影入场** | S1 | 逆光 / 门框 / 烟尘，人物从亮处走来，先黑后亮 | 主体占画 1/3，光源在正后方 |
| G2 | **局部先行** | S0→S1 | 脚→腿→腰→武器→脸的上摇；或手入画后镜头拉开 | 上摇 3–5s，匀速 |
| G3 | **环绕运镜** | S1–S2 | orbit / arc，半圈到一圈 | 8–15°/s，匀速 |
| G4 | **慢动作高光** | S2 | 能力发生瞬间放缓，粒子与衣摆悬停 | 30–50% 速度，ramp in → snap back |
| G5 | **轨迹留光** | S2 | 武器划过留下光带 / 残影 | 残留 0.3–0.6s 后消散 |
| G6 | **元素 / 武器召唤** | S2 | 碎片从虚空吸附聚合成形 | 聚合必须有明确的**收束点** |
| G7 | **环境压制** | S2 | 不出招，靠气压让碎石浮起、火苗倒卷、雨滴悬停 | 作用半径明确，边界清晰 |
| G8 | **冲击定格** | S2→S3 | 一次冲击后画面硬静止 | 0.3–0.5s |
| G9 | **打破第四面墙** | S3 | 角色直视镜头，微微偏头 / 抬眼 | 中近景，眼神对焦镜头 |
| G10 | **收势** | S3 | 武器归鞘 / 披风落下 / 光点消散 / 抬手压帽檐 | 动作幅度小、速度慢 |
| G11 | **执念物特写** | 30s 中段 | 手中旧物、断刀、怀表，浅景深 | 与战斗段形成冷暖反差 |

## 2. 运镜参数基线

| 项 | 基线 | 说明 |
|---|---|---|
| 环绕速度 | 8–15°/s | 慢于 8 显得拖，快于 15 观众跟不上 |
| 推进速度 | 慢推 0.3–0.8 m/s 等效 | S3 的微推用下限 |
| 慢动作 | 30–50% 原速 | 低于 30% 会拖影 |
| 定格 | 0.3–0.5s | 短于 0.3 感觉不到，长于 0.5 以为卡了 |
| 焦距 | 85mm 特写 / 35mm 全身 | 展示片以中长焦为主，避免广角变形 |
| 主光 | **全片单一方向** | 中途换光向 = 剪接事故 |

## 3. 构图惯例

| 拍 | 景别 | 构图 | 主体位置 |
|---|---|---|---|
| S0 | 极特写 / 空镜 | 留白 ≥ 60% | 偏一侧，另一侧留给人 |
| S1 | 全身 / 七分身 | 居中或三分 | 居中偏下，头顶留 10% |
| S2 | 中景 / 近景 | 动势方向留空间 | 顺动势方向前置 |
| S3 | 中近景（签名 Pose） | 居中稳定 | 居中，两侧对称留白 |

## 4. 越轴与连续性

- 全片**不越轴**：角色朝向一致，运动方向一致。
- 若必须换边，用**中性镜头**（正对 / 背对）过渡。
- **环境运动方向**（风、雪、水流）全片一致，是最容易被忽略的一致性项。

## 5. 展示片特有的三个"不要"

1. **不要快速剪辑**：展示片不是预告片，观众需要时间看清脸。单镜 < 1s 的切镜只在 P2 用。
2. **不要逆着人物动势运镜**：人物向右冲，镜头别向左拉。
3. **不要让特效占满画面**：主体必须始终是可辨认的人形（H7 的能力锚要求）。特效占比 **≤ 画面 40%**。

## 6. ASCII 机位摆位图（沟通用）

```
                 [背光 / 主光]
                      ☀
                      |
        Cam2 (侧位)   |   Cam3 (侧位·反向)
              \       |       /
               \      |      /
                \     |     /
                 \    |    /
                  \   |   /
                   [ 角色 ]
                      |
                      |
                 Cam1 (正面·低角度)
                      |
                   [ 镜头 ]

Cam4 = 极低位（膝高）或极近特写（眼/手/执念物），沿角色正前方插入
```

| 机位 | 职责 | 主要用在 |
|---|---|---|
| Cam1 正面低角度 | 亮相、签名 Pose | S1 / S3 |
| Cam2 侧位 | 动势、拔刀、位移 | S2 |
| Cam3 反向侧位 | 环绕的另一半、反打 | S2 长镜头 |
| Cam4 极近特写 | 眼 / 手 / 武器 / 执念物 | S0 / 闪回 / S3 眼神 |

**越轴规则**：Cam2 与 Cam3 之间切换必须经过 Cam1（中性正面）或 Cam4（中性特写），不许直接互换（`04 §4`）。

## 7. 画幅适配

| 画幅 | 构图调整 | 注意 |
|---|---|---|
| 16:9 横屏 | 标准构图 | 主体可偏一侧，另一侧留给动势 |
| 9:16 竖屏 | **主体居中竖向**，全身改为七分身或半身 | 竖屏容不下横向大远景，S1 用中景 |
| 1:1 方屏 | 主体居中，四周留白均匀 | 避免对角线构图 |
| 2.35:1 宽银幕 | 上下留黑边感，主体压中线 | S0 的空镜最有优势 |

## 8. 无字幕约束下的镜头注意（H10 配套）

- 避免"角色低头 / 背对镜头说话"的构图——无字幕时观众读不到信息，必须让**嘴与眼神可见**或**用动作替代**。
- S3 若走 A 式（角色发声），必须给**中近景 + 嘴部无遮挡**。
- 环境里**不要写招牌 / 横幅 / 屏幕文字**，AI 极易生成乱码（负面词见 `06 §3`）。
